<h1>آموزش ساخت کانفیگ TB-Cdn در پاسارگارد</h1>

<h2>1. گرفتن سرتیفیکت برای دامنه‌ها</h2>
<p>ابتدا برای دامنه‌هایی که می‌خواید استفاده کنید، سرتیفیکت بگیرید.</p>
<p>یک ساب‌دامنه برای استفاده در کانفیگ و یک ساب‌دامنه برای اتصال سرور به پنل پاسارگارد ایجاد کنید.</p>
<p>می‌تونید از اسکریپت آماده برای گرفتن سرتیفیکت استفاده کنید. بعد از گرفتن، فایل‌ها را به مسیر زیر منتقل کنید:</p>
<pre>/var/lib/pasarguard/certs/</pre>
<p>این کار را برای هر دو دامنه انجام دهید.</p>

<h2>2. ایجاد هسته جدید در پنل پاسارگارد</h2>
<p>به پنل برید و یک هسته جدید بسازید. کانفیگ زیر را در بخش اینباند قرار دهید و ذخیره کنید:</p>
<pre>{
  "tag": "VLESS+WS+NONE+4220",
  "listen": "0.0.0.0",
  "port": 4220,
  "protocol": "vless",
  "settings": {
    "clients": [],
    "decryption": "none"
  },
  "streamSettings": {
    "network": "ws",
    "security": "none",
    "wsSettings": {
      "acceptProxyProtocol": false,
      "path": "/admin?ed=1024",
      "host": "yourdomain.com",
      "headers": {}
    }
  },
  "sniffing": {
    "enabled": false
  }
}</pre>

<h2>3. نصب PG-Node روی سرور</h2>
<p>دستور نصب:</p>
<pre>sudo bash -c "$(curl -sL https://github.com/PasarGuard/scripts/raw/main/pg-node.sh)" @ install</pre>

<p>مسیر سرتیفیکت‌ها:</p>
<pre>
سرتیفیکت اصلی:
/var/lib/pasarguard/certs/sub.yourdomain.com/fullchain.pem

کلید خصوصی اتصال سرور به پنل:
/var/lib/pasarguard/certs/connecting.fibonet.shop/privkey.pem
</pre>

<p>پورت‌های مجاز HTTPS:</p>
<pre>443, 2053, 8443, 2083, 2087, 2096, 3087, 3096</pre>

<h2>4. اتصال نود به پنل پاسارگارد</h2>
<p>در پنل، به مسیر گره‌ها / Nodes برید و یک نود جدید بسازید.</p>
<p>کلید API که ایجاد شده رو کپی کرده و داخل سرور وارد کنید.</p>
<p>بعد از نصب سرتیفیکت، فایل‌ها رو از سرور کپی کنید و داخل پنل قرار بدید.</p>
<p>برای دامنه، آدرس یکی از دامنه‌هایی که قرار نیست تیک پروکسیش روشن باشه رو انتخاب کنید.</p>

<h2>5. اضافه کردن کانفیگ به گروه و هاست</h2>
<p>کانفیگ رو به گروه و هاست اضافه کنید.</p>
<p>بعد از تست اتصال، تیک پروکسی دامنه اول (که پشت کانفیگ استفاده شده) رو روشن کنید.</p>
<p>ساب‌دامنه‌ای که برای اتصال بین سرورها هست، تیک پروکسیش روشن نشه.</p>
